# NOOS / A living instrument

NOOS is an interactive audiovisual field that transforms text, touch, breath, and microphone input into a deterministic visual memory.

## Experience

- Seed-driven particle field with repeatable initial conditions
- Three field states: Resonance, Imprint, and Void
- Pointer and touch disturbances
- Optional microphone-reactive geometry
- Generative Web Audio drone
- Live coherence, entropy, and memory telemetry
- PNG glyph export
- Responsive layout with no build step or backend

## Run locally

Open `index.html` directly, or serve the directory with any static server:

```bash
npx serve .
```

## Deploy

Import this repository in Vercel and deploy with the default static settings. No environment variables are required.

## Privacy

All signals are processed in the browser. NOOS is a speculative instrument, not a diagnostic or scientific measurement tool.
